# Earlier research methods

These earlier experiments are retained as implementation background. The supported entry point is `python -m genetics_app`, documented in the main README.

These scripts cover array quality, ancestry projection, ClinVar and GWAS matching, score coverage, imputation, phasing, and mitochondrial input preparation. They expect their own research-directory layout and are not imported by the app. The requirements snapshot applies to those historical experiments; install the application's `research` extra for the current pipeline.
